# 0Captus
## A Field Guide to the Extraction Leviathans

A forensic mythology compendium mapping the architecture of institutional 
extraction — surveillance infrastructure, asset forfeiture pipelines, 
algorithmic targeting systems, and the coordination layer that connects them.

Sourced from primary government documents. Eight analytical frameworks. 
One public interest analysis.

**To view the document:** Download both files and keep them in the same 
folder. Open `Comprehensus_Redacted_v3_light.html` in any browser.

The font file `comprehensus-fonts.css` must be in the same folder as the 
HTML file for the document to render correctly.
